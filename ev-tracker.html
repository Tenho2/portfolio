    📥 Import charge data

    Load sessions from a file. Supported: .csv, .tsv and .json. Existing sessions are kept; the imported ones are added to the vehicle in the Vehicle column, or to the currently selected vehicle when that column is missing or empty.

    Templates for a new file are in Export data, above.
    How the file must be formatted

    Column names (CSV / TSV)

    The first row must be a header row. Column names are matched case-insensitively and spaces, underscores and dashes are ignored, so Energy (kWh), energy_kwh and ENERGY all work.

    ColumnRequiredAccepted values
    dateyesYYYY-MM-DD, e.g. 2026-09-28
    timeyesHH:MM 24-hour, e.g. 08:15
    locationyesAny text, e.g. Supercharger Vaasa
    energyyesNumber in kWh, e.g. 52.4
    durationnoHH:MM or decimal hours, e.g. 00:45 or 0.75
    mileagenoNumber in km, e.g. 45000
    costnoNumber in euros, e.g. 12.50. Leave empty to use your price per kWh
    vehiclenoVehicle name. A new vehicle is created for an unknown name
    notesnoAny text
    fast, home, favouritenoyes/no, true/false, or 1/0

    Example CSV

    date,time,duration,location,energy,mileage,cost,vehicle,notes,fast,home,favourite
2026-09-28,08:15,00:45,Supercharger Vaasa,52.4,45000,12.50,Vehicle 1,150 kW 20-80%,yes,no,yes
2026-09-20,19:40,01:30,Home,30,44810,,Vehicle 1,,no,yes,no

    TSV

    Identical to CSV but the columns are separated by a tab character. Saving a CSV as “Tab separated (.tsv)” from Excel or Google Sheets works.

    JSON

    Either a plain array of session objects, or a file previously produced by Backup JSON (which may also contain vehicles, favourites and pricePerKwh).

    [
  {
    "date": "2026-09-28",
    "time": "08:15",
    "duration": "00:45",
    "location": "Supercharger Vaasa",
    "energy": 52.4,
    "mileage": 45000,
    "cost": 12.5,
    "vehicle": "Vehicle 1",
    "notes": "150 kW",
    "fast": true,
    "home": false,
    "favourite": true
  }
]

    Notes

    • The first line of a UTF-8 file may include a byte order mark; it is ignored.
    • Text containing a comma, a semicolon or a quote must be wrapped in double quotes ("Name, Inc.").
    • Rows that are missing a date, time, location or a numeric energy value are skipped and listed with the reason, so nothing is imported silently.
